# Veri politikası

Bu depo, üçüncü taraf ham verileri yeniden dağıtmaz. Veriler özgün sağlayıcılarından ve ilgili kullanım koşullarına uygun biçimde edinilerek yalnız yerel çalışma alanında tutulur.

- `metadata/`, veri sözlüğü, şema, veri hazırlama özeti ve deney bölme kayıtlarını içerir.
- `aggregates/`, yalnız kamuya açık paylaşım için uygun, kişi düzeyi kayıt içermeyen ve yeterli yuvarlama uygulanmış TGSS özetlerini içerir.
- `raw/`, yerel ham veri alanının beklenen yapısını açıklar. Bu dizinde README dışında hiçbir dosya Git tarafından izlenmez.

TGSS mikro verisi, hazırlanmış satır düzeyi TGSS verisi, satır düzeyi tahminler ve küçük hücre sıklıkları bu depoda paylaşılmaz. TGSS verisine erişim, veri sağlayıcının resmî başvuru ve kullanım koşullarına tabidir.

Karşılaştırma veri setleri özgün kaynaklarından edinilmelidir. Depo, kaynakların yeniden dağıtım haklarını üstlenmez.
